# AGM Chile — propuesta de sitio web (demo)

Demo estática de la propuesta de rediseño para **AGM Chile** (agm.cl), preparada por **Agenciados**.

- Home, catálogo con filtros, 30 colecciones, 135 fichas de producto, blog, nosotros y contacto.
- **Landing B2B con cotizador por volumen** en `/empresas.html`: el visitante arma su lista, ajusta cantidades y la envía por WhatsApp o correo.
- HTML, CSS y JS estáticos, sin frameworks ni servidor.

## Aviso
Demo de presentación: los precios son referenciales según la lista pública vigente al momento de la captura y el sitio está marcado como `noindex` para no competir con agm.cl en buscadores.
